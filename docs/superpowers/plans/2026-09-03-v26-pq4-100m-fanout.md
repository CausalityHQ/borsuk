# V26 PQ4 100M Fan-Out Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove authenticated 100M-by-96 PQ4 construction and local ten-shard search with parallel training, deterministic merging, active monitoring, and a 15ms p99 target.

**Architecture:** Ten query-independent synthetic corpus ranges are generated and built independently on AWS Spot, then their authenticated local Arrow snapshots are opened by one bounded `Pq4ShardedIndex`. Timed search fans out to all ten shards and deterministically merges exact local top-k; the controller owns S3/AWS interaction, monitoring, receipts, cleanup, and termination.

**Tech Stack:** Rust 2024, Rayon, Apache Arrow IPC, Parquet, SHA-256, canonical JSON, Python 3.12 stdlib controller, AWS CLI/EC2/S3 Spot.

**Spec:** `docs/superpowers/specs/2026-09-03-v26-pq4-100m-fanout-design.md`

## Global Constraints

- The 100M corpus is newly generated `synthetic-clustered-100m-96`; never duplicate or relabel Deep-Image rows.
- Use ten exact global intervals of 10,000,000 rows and global eight-byte little-endian source IDs.
- Build workers cannot access query or truth artifacts.
- Serving opens a nonempty contiguous set of at most 256 local authenticated snapshots; the campaign requires exactly ten. It has no network, page, loader, or compatibility surface.
- Search ordering is `(squared_distance, shard_ordinal, source_ordinal)` and arrival order is never authority.
- Gate aggregate Recall@10 at 995,000 ppm, every-query recall at 800,000 ppm, p99 at 15,000,000 ns, projected bytes at 2,336,975,744, RSS below 3 GiB, PSI at 1%, and swap growth at zero.
- Use exact focused tests during repair, one affected gate per stable slice, and only one final Clippy/full-workspace assurance.
- Poll active remote work every 30 seconds and stop on the exact health, pressure, progress, and wall criteria in the spec.
