# Experimental release status

BORSUK is unreleased. The current Rust APIs are documented in the
[native API guide](../api.md). They include generation publication, pinned
search, durable mutations and recovery, callable compaction, and bounded GC.

Use a pinned source checkout. API and artifact stability are not guaranteed.
The [development measurement](../benchmarks.md) describes one tested workload;
it is not a release qualification or a matched vendor win.

See [source builds](rust-source-packages.md) and
[publication/maintenance boundaries](../consistency.md).
