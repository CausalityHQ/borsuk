Native Rust API

The current path opens a small authenticated semantic directory, reads selected centroid leaves, shortlists two-bit SOURCE candidates, and scores SQ8 vector ranges. This is approximate retrieval with quantized scoring.

Rust modules expose build and conditional publication, pinned open and search, logical IDs, durable mutation snapshots and recovery, callable compaction, and bounded garbage collection.

Start from the fixtures

Read the examples at a pinned checkout before adapting them to your application. The caller supplies credentials, trusted-head delivery, and explicit resource limits.

  • Generation construction, publication, reload, and failure checks
  • Logical IDs, recovery, compaction, and GC
  • Delayed-delete checks

Coordinated readers and maintenance must use the same directory. Lifetime locks protect cooperating callers on one host or shared local filesystem; direct remote openers and other hosts are outside that protection.

Experimental language bindings

Python and TypeScript expose separate create/add/search APIs. Their local examples do not exercise the current native generation route, and native measurements do not describe their performance.
