Vector search over object storage.

Blob-Oriented Retrieval with Segmental Unified KNN

BORSUK is a Rust library that runs search in your process. The current native path opens a small authenticated semantic directory, reads selected centroid leaves, shortlists two-bit SOURCE candidates, and scores SQ8 vector ranges.

APIs, defaults, and stored formats can change. Local synthetic fixtures and S3 measurements cover specific operations. Python and TypeScript bindings have separate experimental API surfaces.

Authenticated generations

Native APIs construct metadata, publish immutable objects before a conditional head, and open a pinned generation. Fixtures check identity, corruption, and resource admission.

Mutations and recovery

Durable snapshots preserve updates and tombstones. Logical-ID search includes the supplied snapshot and suppresses replaced or deleted base IDs before top-k.

Callable maintenance

Compaction and garbage collection have lifecycle fixtures. Reader coordination covers cooperating callers on one host or shared local filesystem.

Explicit resource limits

Callers set modeled memory, active queries, scratch, and separate SOURCE and SQ8 I/O limits. Whole-process memory needs separate measurement.
