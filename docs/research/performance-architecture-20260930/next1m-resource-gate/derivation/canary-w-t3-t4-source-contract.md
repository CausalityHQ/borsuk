## (3) T3: root cause traced; no function text reaches the manager
Trace: `declare -f cg_inner` yields correct bash (`jq -cn "${args[@]}" '$ARGS.named'`, `key=${name//./_}`, `d=${d%/*}`), but the OLD tail passed it as ONE word of `systemd-run ... bash -c "<text>" _ PIDFILE`. systemd-run(1): the manager expands "$" in command-line words after the command is passed (services since v254; literal dollar needs "$$" or --expand-environment=no); `${NAME}` inside a word is replaced by the variable (invalid names too, as "Invalid environment variable name evaluates to an empty string: args[@]" shows). So "${args[@]}" became "" and jq received `jq -cn "" '$ARGS.named'`: an empty program = the exact a0008 error, with no resource line written. Only the first jq ran because set -e aborted.
