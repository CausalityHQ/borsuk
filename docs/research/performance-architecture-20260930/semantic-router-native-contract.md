# Native semantic generation integration contract

This completes the existing measured mechanism after the shared router core.
The first four-file core slice is active; this document does not change its
ownership. No cloud launch follows until the entire serving/lifecycle slice
is qualified. No new nomination or quantization policy is introduced.

## Format and startup

Use one new current generation format (v7), with explicit graph/semantic
discovery. Preserve graph as the contemporaneous measured control mode.
Reject incompatible old generation envelopes; do not add a historical v4/v2
serving reader. Package immutable historical payloads into the current plane
authority with unit digests for benchmark parity, without source/SQ8
reencoding, row reorder, mean/prototype changes or router refit.

The generation root binds geometry, generation/epoch, canonical source,
source plane/SQ8 identities and the selected discovery artifact descriptor.
A router construction's original input receipt is not a recursive generation
root dependency. Validate source identities directly; never waive a mismatch
because the artifact came from an earlier experiment.

Authenticate the bounded generation manifest before deriving the exact
startup/upload/GC roster. Keep the generation-manifest 64 KiB trust boundary.
Only the explicitly named authenticated router root may use its 1 MiB bound;
do not increase the cap for arbitrary JSON metadata. Semantic startup loads
codec mean/receipt, source/SQ8 page authorities, router root and membership,
but no full centroid, graph or leaf payload. Admit decoded and encoded
metadata copies and retired-generation pins before allocation.

## Query and accounting

Use the qualified library router, original-query two-bit preparation and
exact existing cosine normalization. Fetch every selected whole leaf with
bounded parallelism, strong object ETag/size/range identity, exact body length
and the root-bound per-leaf digest. Validate membership, unit IDs and selected
partition, then release leaf payload buffers. Keep all nominated units and
seed completion within the nominated page closure. Reuse shared source-cover,
source scoring/planning and authenticated native SQ8 ranking; no scoring copy
or full-source fallback. Release source buffers before SQ8 fetches.

Retain the fixed 100k caps from semantic-router-cold-http-gate.md. Zero
leaf/source/SQ8 cache; retained root/membership is separately charged.
Charge all concurrent-query scratch/buffers, admission and generation swap.
A lower limit must reject before allocating/submitting excluded work;
failure must retain incurred charges and drain admitted reads.

Expose one admitted full ObjectStore search seam through the same generation
semaphore/validation/ranking path as OneAttemptS3. Keep the internal
unadmitted helper private. Propagate router/source/SQ8 charges on success
and failure; emit stage intervals and observed request overlap.

At the existing native HTTP transport, count request attempts/method/status,
failures and consumed response payload bytes without credentials/object-key
logging. Keep redirects and both SDK/transport retries disabled. Use a live
HTTP fixture to prove one attempt under failure and accounting under success.
Label consumed payload separately from authenticated bytes and from total
network bytes: dropped/unread error bodies and headers are not magically
measured wire traffic. For concurrent offered load, process aggregate counters
must not be presented as independent per-request deltas. Record unknowns.

## Publication, incremental maintenance and recovery

Reuse existing immutable upload and conditional-head publication. Validate
all router bodies, full partition and original centroid/prototype identity
before publishing. Upload the exact format-specific roster; HEAD becomes
visible last. Partial upload cannot become a valid generation.

Preserve authenticated logical-ID upsert/delete snapshots and base-root
bindings. Compaction defaults to the base generation's concrete discovery
mode; an explicit mode change is permitted, recorded and validated.
Resolve/store that concrete mode in the durable job before build so restart
cannot silently downgrade semantic discovery to graph. Prepared-root
validation must bind job, input, mode and target identities. Preserve sealed
mutations, empty generations, recovery fences and caller-owned pin accounting.

GC derives current-generation retention from the authenticated descriptor,
including root/membership/leaves/source/SQ8/canonical objects. Keep in-process
automatic/callable compaction and GC; no maintenance host/service. Reject
unrecognized mode/size instead of falling back or deleting unknown live data.

## Acceptance and boundary

One bounded deterministic InMemory/recording-store parity test exercises
more than eight leaves, partial tail and nontrivial logical IDs, with graph
objects absent. Compare lazy/eager shared-core nomination, seed completion,
plans and ordered native IDs. Selected-leaf corruption and reduced budgets
must reject before downstream reads and preserve accounting. Include
semantic publication/HEAD-last, upsert/delete visibility, restart mode,
compaction and GC retention in affected lifecycle tests.

Actual affected compilation/tests, release HTTP build, workspace Clippy and
complete workspace test compilation are required on the exact source; no
overlapping Cargo or mock success. Run one final stable full execution scope
before release. Root then freezes source, binaries, object authority,
controller, resources and cleanup before the declared cold HTTP cell.
