The all32 panel already participates in research;it is not a blind holdout.
Canonical input is normalized f32,not original unnormalized corpus vectors;
precision,normalization and ties remain possible contributors. Do not call
this quantization-only attribution. Full corpus files were streamed for hash
authentication;that cost is NOT a production query cost or latency measurement.

panel, by explicit rank/set verification. This motivates a bounded top16
refinement candidate. It does not establish the new fetch protocol, payload
authentication,cost,latency or full1000 quality. Production refinement must
authenticate selected canonical ranges without hydrating a whole corpus.

whether reconstructed-SQ8 cosine finalization changes the covered-neighbor

inspection and an independent literal oracle must establish the actual norm
semantics;retain gains AND displaced losses over the whole development panel.
