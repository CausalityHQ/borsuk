# Cold SOURCE score overlap: mean gain, mixed tails

## Decision
Retain the frozen implementation as a research/Pareto candidate; do not promote it into the production default. The preregistered 68-query screen FAILED the requirement for a 5% p95 reduction in both paired comparisons. This failure is immutable. It is not an execution failure.

The valid mean-wall, p90 and CPU improvements support one prospective, unchanged-source full-1000 cold paired confirmation to distinguish broad benefit from a mixed small-panel tail result. That is a new full-cohort falsifier, not a rerun of this panel or a retrospective GO. Keep the same tail thresholds and incumbent until qualified evidence supports promotion.

## Architecture and scope
Generic Rust ANN: resident semantic routing, authenticated 2-bit SOURCE units, SQ8 pages, then canonical FP32 reranking. The intervention scores only the original mandatory units after a complete response authenticates on the existing two SOURCE workers, while other reads remain pending. It preserves ordered error draining, output math, nominations, completion, page cover and all GET/byte caps. No cross-query SOURCE cache is used.

Cohere Wikipedia D1024 cosine k10 is an evaluation fixture. Dimensions, geometry, IDs and limits remain explicit library inputs; generic dimensional/tail/non-dense-ID and cancellation tests remain required. No dataset-specific scoring/routing rules were introduced. The 64-leaf/16-rerank selections are experiment settings, not a claimed universal optimum.
