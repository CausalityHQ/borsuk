1. **P1 — Replay omits full-cover byte admission. Source bug.**

   **Smallest reproducer:** With three resident-capable slots, let one block contain B bytes and set `source_byte_budget=B`. Replay queries covering page 0, page 2, then pages {0,2}. The first two queries each fetch B; the third has two hits and zero fetched bytes, so cache replay accepts it. Native admission rejects its 2B original cover. This is a model-level reproducer; full-reader execution remains unverified.

   **Smallest fix:** Retain the cover byte total and require it to fit `source_byte_budget` before changing replay state. Add this sequence as a negative oracle. Otherwise coherent counters and seals can describe execution that native admission forbids.

2. **P2 — Cache allocation precedes combined FP32 admission. Contract gap.**
   `crates/borsuk/src/bin/check_cohere_native_baseline.rs:2681` allocates through `with_source_cache`; the complete FP32 memory check follows at `:2683`. The cache allocator checks baseline-plus-cache at `two_bit_generation.rs:2339`, while FP32 memory adds its query reservation at `:3940`.

   **Smallest reproducer:** Choose a cap C where baseline+cache ≤ C < baseline+cache+FP32-query-reservation. Cache allocation succeeds before startup rejects the configuration.

   **Smallest fix:** Preflight the combined reservation before allocating cache storage, reusing the same cache-charge calculation. This is avoidable allocation for an inadmissible configuration—not evidence that a query exceeds the configured cap.

3. **P2 — New replay tests cannot exercise replacement or mixed-range ordering. Test gap.**
   `crates/borsuk/examples/compare_native_replay.rs:16533` uses the 33-row fixture created at runner `:3738`. That provides one block and no replacement. Individual counter mutations do not test whether replay computes the correct state across collisions.

   **Smallest discriminating test:** Use 513 rows, one slot, and two original ranges covering blocks 0 and 2. Repeat the query. On the second pass, block 0 misses and block 2 hits **before insertion**; inserting block 0 then evicts the tail. Check all counters, tail occupancy and transport charges. Also add finding 1’s over-budget warm-cover refusal. Existing native tests provide useful coverage but do not verify this new reader.
