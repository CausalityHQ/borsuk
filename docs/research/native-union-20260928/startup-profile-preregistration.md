Purpose: resolve the measured4.514–4.865 s remote-open gap from the closed
peer1M development campaign. This is bounded profiling, not an architecture
arm or a vendor/quality qualification. Keep sequential GETs, artifact layout,
identity authentication, admission, decoder, nomination and scorer unchanged.
New counters add bounded per-file records and monotonic timing calls. Their
overhead is included; historical uninstrumented timings are descriptive context,
not a matched performance control for a later buffered/parallel candidate.

startup-profile-config.json freezes previously verified FIRST1M D768 cosine
ReLAION/CoHere generations and their existing k10 namespaces. Six startup-only
samples interleave[ReLAION,CoHere]*3. Each uses a fresh native process, exact
root/generation/control and nine metadata files. Frozen byte totals are
256,694,403 B /256,694,456 B. No ANN query, GT read, recall/QPS/first-query or
live competitor measurement. S3 service cache is uncontrolled; restarted
processes alone do not establish a cold S3 cache.

Per object report GET-header wait, bytes, transport chunk count, combined
stream/output wall time and awaited writes/flush (a subset of that time).
Report total staging, authenticated local decode and total remote open,
head read and process-to-health readiness separately. File creation/path work
and authentication outside the stream loop remain in total staging. Awaited
write time includes executor/disk waits, not exclusively physical disk work.
Counter names do not represent billed AWS request counts; no transport retries
are configured. Collect GNU time and cgroup resources.

Accept diagnostic evidence only if all six starts authenticate exact frozen
metadata roster/bytes, distinct names, nonnegative counters and nested timing
bounds, native authority/listener and clean deliberate process closure. A
failed/incomplete start invalidates this profiling cell; preserve its terminal
and do not tune or replace automatically. Three repeats per dataset are
exploratory; do not claim population percentile precision from them.
