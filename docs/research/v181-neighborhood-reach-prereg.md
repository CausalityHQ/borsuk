# V181 generic neighborhood reach preregistration

V180's fresh source holdout lost 33/6,400 exact truth positions outside the
width-8 physical candidate universe and six more to PQ top-672 ranking.
This gate asks whether a **generic wider neighborhood** around the same
frozen nominees has enough source-truth reach to merit a ranking/physical
planner experiment. It does not tune a query ID or corpus-size threshold.

Use ReLAION-1M D768 source pseudoquery SHA ranks 897–1152, disjoint from
V177/V178/V180; fit ranks 897–1024 and holdout 1025–1152, 128 queries each.
Freeze the V115 nominee and V164 physical unit rosters before exact source
truth. Compare widths 8, 16 and 32 complete 32-row units. Report candidate
size distribution and exact-source truth containment separately by split.
The query source row is excluded from truth. No SQ8 reads or physical plan
is implied by candidate containment.

For 128 holdout queries, the V155 used-validation exact-source returned rate
transfers to a **source-only, unpaired screen** of at least 12,745/12,800
truth positions, with p05 at least 98. Select the smallest tested width
meeting both gates. If no width passes, reject a local physical-neighborhood
candidate expansion as the next production method and design an additional
nonlocal candidate source. A pass only licenses a fresh GT-blind ranking and
physical budget gate; it does not prove returned recall, latency, serving RAM,
or a production default. Memory and page caps remain caller and recall
policies derived from measured cost, with no fixed 100M knee.

Run one immutable Causality Spot cell, S3-seal rosters before source truth,
hash closed artifacts, and terminate the instance at its terminal marker.
