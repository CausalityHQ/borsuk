# Callable crash-resumable compaction

One owned in-process worker holds a standard file lock for a caller-owned maintenance directory bound to one index prefix. Read the current authenticated head/delta; no delta means no work. Seal through the existing CAS, stream canonical/delta preparation, build native SQ8/metadata and CAS-publish the replacement. Use the real empty root for all-deleted output. Builders remain query-blind. Source/build/upload payload and temporary disk are admitted; caller charges other query pins/runtime separately.

A durable base/mutation journal and ready record install with sync/no-clobber. Before ready, partial staging is recomputed from authenticated inputs. After ready, authenticate prepared input/target identities and publish without re-uploading SQ8; use a newly claimed UUID namespace per first build to avoid rewriting an ETag-pinned blob. Resume after precommit failure and reconcile lost head acknowledgements. One directory per index prevents overlapping calls there; other processes/directories require caller coordination. Owned worker keeps lock if the awaiting future is dropped. Remove local completed staging; remote reader-safe GC remains a separate next gate.
