# Experimental evidence scope

Public descriptions follow the current native code and its fixtures.
Performance statements refer to a specific measurement's source revision,
configuration, dataset, query panel, hardware, resource limits, and protocol.

The [current measurement guide](benchmarks.md) links the latest decision and
receipts. A passing development panel does not establish broad capacity, cost
savings, production readiness, or a commercial performance win.

Archived reports in [docs/research](research/README.md) remain immutable
evidence for the revisions they measured. Their capabilities and numbers are
not carried into the current product description.
